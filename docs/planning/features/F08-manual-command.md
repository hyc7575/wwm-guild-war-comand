# F08 수동 명령

| 항목 | 내용 |
|---|---|
| 단계 | Phase 1 (MVP). 프리셋과 휴대폰 리모컨은 Phase 2 |
| 우선순위 | Must |
| 관련 문서 | [F03 명령 추출](F03-command-extraction.md), [F07 명령 상태](F07-command-state.md) |

## 왜 필요한가

- 음성인식은 반드시 틀릴 때가 있다. 그때 메인오더가 바로잡을 길이 있어야 한다.
- 소음이 심하거나 STT가 꺼졌을 때도 서비스가 멈추면 안 된다.
- 다만 메인오더는 게임 중이라 브라우저를 오래 조작할 수 없다. 그래서 수동 명령은 "가장 적은 클릭"이 핵심이다.

## 아이디어

| 안 | 내용 | 판단 |
|---|---|---|
| 빠른 버튼 패널 | 대상 칩 → 행동 버튼 → (위치) → 발행 | **채택**. 3번 클릭 이내 |
| 키보드 단축키 | 숫자(파티), 글자(행동), Enter(발행), Esc(직전 취소) | **채택**. 브라우저 탭에 초점이 있을 때만 동작한다 |
| 글자 입력 | "3파티 우측 방어"를 입력하면 F03 파서로 해석 | **채택**. 파서를 재사용하므로 비용이 적다 |
| 후보 한 번 클릭 발행 | F03 후보를 그대로 발행하거나 고쳐서 발행 | **채택** |
| 전술 프리셋 | "A작전" 버튼 하나로 여러 파티 명령 동시 발행 | Phase 2 |
| 휴대폰 리모컨 | 메인오더가 휴대폰으로 버튼을 누름. 게임 창을 내리지 않아도 된다 | Phase 2. 메인오더 권한을 두 번째 기기에 넘기는 방법이 필요하다 |
| 전역 단축키 | 게임 중에도 키로 취소 | 불가. 브라우저는 다른 창에 초점이 있을 때 키 입력을 받을 수 없다. 별도 프로그램이 필요해 "설치 없음" 원칙과 충돌한다 |

## 기능 요구사항

| ID | 요구사항 |
|---|---|
| FR-F08-1 | 대상(전체, 파티 여러 개), 행동, 위치(선택)를 골라 발행한다. 3번 클릭 이내 |
| FR-F08-2 | 행동을 누르면 위치 없이 바로 발행하는 옵션이 있다 (위치가 필요 없는 후퇴·대기용) |
| FR-F08-3 | 키보드 단축키로 대상·행동·발행·직전 취소를 할 수 있다. 단축키 목록을 화면에 보여 준다 |
| FR-F08-4 | 글자 입력을 F03 파서로 해석하고, 결과를 확인한 뒤 Enter로 발행한다 |
| FR-F08-5 | F03 후보를 한 번 클릭으로 발행하거나, 버튼 패널에 채워 고친 뒤 발행한다 |
| FR-F08-6 | "직전 취소" 버튼은 가장 최근 발행 명령(음성·수동 무관)을 취소한다. 화면에서 가장 큰 버튼 중 하나다 |
| FR-F08-7 | 파티별 현재 명령 옆에 취소 버튼이 있다 |
| FR-F08-8 | 수동 명령은 `source: MANUAL`로 기록되어 세션 요약에서 따로 센다 |
| FR-F08-9 | 음성인식이 꺼져 있어도 수동 명령은 동작한다 |

## 사용자 스토리

### US-F08-1 버튼으로 발행
메인오더로서, 음성인식이 틀렸을 때 버튼 몇 번으로 바른 명령을 보내고 싶다.

1. [3] → [방어] → [우측] → [발행]으로 "3파티 방어 우측"이 발행된다.
2. 대상은 여러 개 고를 수 있다.
3. 발행하면 선택이 초기화된다.

### US-F08-2 직전 명령 취소
메인오더로서, 잘못 나간 명령을 한 번에 취소하고 싶다.

1. [직전 취소] 또는 Esc 키로 가장 최근 명령이 취소된다.
2. 동맹원 화면은 이전 명령으로 돌아간다 (F07).
3. 연속으로 누르면 그 이전 명령도 차례로 취소된다.

### US-F08-3 후보 발행
메인오더로서, 애매해서 보류된 명령을 확인하고 바로 보내고 싶다.

1. 후보 카드의 [발행]을 누르면 그대로 발행된다.
2. [수정]을 누르면 버튼 패널에 값이 채워진다.
3. 후보는 10초 뒤 사라진다.

### US-F08-4 글자로 발행
메인오더로서, 채팅하듯 짧게 입력해서 발행하고 싶다.

1. "3파티 우측 방어"를 입력하면 입력창 아래에 해석 결과가 바로 보인다.
2. 해석이 안 되면 "해석할 수 없습니다"가 보이고 발행 버튼이 비활성화된다.
3. Enter를 누르면 발행되고 입력창이 비워진다.

## 열린 질문

- 메인오더가 실전에서 브라우저를 볼 여유가 정말 있는가? 없다면 수동 명령은 동맹전 전·휴식 시간용이 되고, 휴대폰 리모컨(Phase 2)의 우선순위가 올라간다. PoC 관찰로 확인한다.
