# F05 전술 HUD

| 항목 | 내용 |
|---|---|
| 단계 | Phase 1 (MVP). 모바일 최적화와 작은 창 모드는 Phase 2 |
| 우선순위 | Must |
| 관련 문서 | [F06 파티별 표시](F06-party-view.md), [F07 명령 상태](F07-command-state.md) |

## 왜 필요한가

- 동맹원은 전투 중 화면을 1초 정도만 볼 수 있다. 문장을 읽게 하면 늦는다.
- 휴대폰, 보조 모니터, 알트탭 등 보는 환경이 제각각이다.

## 설계 원칙

1. **1초 안에 읽힌다.** 행동 아이콘, 위치, 대상 순으로 크게 보여 준다.
2. **색에만 의존하지 않는다.** 색과 함께 아이콘과 글자를 쓴다. 색각 이상인 사람도 구분할 수 있어야 한다.
3. **변화가 눈에 띈다.** 새 명령, 재강조, 정정, 취소를 서로 다른 움직임으로 보여 준다.
4. **오래된 명령은 물러난다.** 경과 시간을 보여 주고, 오래된 명령은 흐리게 한다.
5. **어두운 화면이 기본이다.** 게임과 함께 보므로 눈부시지 않아야 한다.

## 시각 언어 [제안]

| 행동 | 아이콘 | 색 계열 | 표시 문구 |
|---|---|---|---|
| GATHER | 모이는 화살표 4개 | 파랑 | 집결 |
| MOVE | 앞쪽 화살표 | 흰색 | 이동 |
| ATTACK | 칼 | 빨강 | 공격 |
| DEFEND | 방패 | 청록 | 방어 |
| RETREAT | 뒤쪽 화살표 | 주황 | 후퇴 |
| SUPPORT | 더하기 | 초록 | 지원 |
| HOLD | 일시정지 | 회색 | 대기 |

| 변화 | 표현 |
|---|---|
| 새 명령 | 카드 테두리가 1초 동안 번쩍인다 + 선택 시 알림음 |
| 재강조 (같은 명령 반복) | 카드가 한 번 커졌다 돌아온다 |
| 정정 | "정정" 배지, 바뀐 부분만 강조 |
| 취소 | 줄 긋고 0.5초 뒤 이전 명령으로 바뀐다 |
| 오래됨 (3분 [제안]) | 투명도 60% |

위치는 글자(예: "우측")와 함께 좌·중·우 3칸 막대에서 해당 칸을 밝혀 보여 준다. 지도 기반 시각화는 Phase 3이다.

## 화면 배치

### 동맹원 기본 화면 (휴대폰 세로)

```
┌───────────────────────────┐
│ ● 연결됨   내 파티: 3파티 ▼ │  ← 상태줄
├───────────────────────────┤
│        [방패 아이콘]        │
│          방어               │  ← 내 파티 현재 명령
│          우측               │     (화면의 절반)
│   [ 좌 | 중 | ■우 ]         │
│   12초 전 · 3파티           │
├───────────────────────────┤
│ 전체: 집결 · 중앙 (2분 전)  │  ← 전체 명령
├───────────────────────────┤
│ 1파티 공격 중앙 │ 2파티 대기 │  ← 다른 파티 (작게)
│ 4파티 지원→3   │ 5파티 —   │
├───────────────────────────┤
│ 최근 이력 ▸                 │
└───────────────────────────┘
```

### 보조 모니터 (가로, 넓은 화면)

내 파티 카드를 왼쪽에 크게 두고, 오른쪽에 모든 파티 격자와 이력을 함께 보여 준다.

### 작은 창 모드 (Phase 2)

모니터가 하나인 사용자는 게임 창 위에 작은 창을 띄운다. Chrome의 Document Picture-in-Picture API를 쓰면 항상 위에 있는 작은 창을 만들 수 있다. 단, 게임이 전체 화면 독점 모드면 가려진다. 창 모드나 테두리 없는 창 모드에서만 동작하므로 PoC에서 확인한다.

## 사용자 스토리

### US-F05-1 한눈에 명령 파악
동맹원으로서, 화면을 잠깐 봐도 내가 할 일을 알고 싶다.

1. 내 파티 카드에 행동 아이콘, 행동, 위치가 화면 높이의 절반 안에 크게 보인다.
2. 1초 판독 테스트를 통과한다 (NFR-F05-4).
3. 명령이 없으면 "대기 중인 명령 없음"을 흐리게 보여 준다.

### US-F05-2 새 명령 알아차리기
동맹원으로서, 새 명령이 오면 화면을 보지 않아도 알고 싶다.

1. 내 파티나 전체 대상 명령이 오면 짧은 알림음이 울린다.
2. 다른 파티 명령에는 알림음이 울리지 않는다.
3. 알림음은 디스코드 음성을 가리지 않도록 0.3초 이하로 짧다.
4. 브라우저가 소리를 막으면 첫 클릭 때 소리를 켜도록 안내한다.

### US-F05-3 휴대폰을 보조 화면으로
동맹원으로서, 휴대폰을 세워 두고 보조 화면으로 쓰고 싶다.

1. 화면이 꺼지지 않는다.
2. 세로 화면에서 스크롤 없이 내 파티 명령과 전체 명령이 보인다.
3. 화면이 꺼졌다 켜지면 바로 현재 명령을 다시 받아 보여 준다 (F10).

### US-F05-4 변화 구분
동맹원으로서, 명령이 바뀐 것인지 같은 명령을 다시 강조한 것인지 구분하고 싶다.

1. 새 명령, 재강조, 정정, 취소의 움직임이 서로 다르다.
2. 정정된 명령은 바뀐 부분이 강조된다.
3. 취소되면 이전 명령으로 돌아갔다는 것이 보인다.

## 열린 질문

- 알림음을 기본으로 켤까? 동맹원 디스코드 음성과 겹칠 수 있다. MVP는 "내 파티 명령만, 기본 켬"으로 시작하고 실전 의견을 듣는다 **[제안]**.
- 게임 내 오버레이는 MVP 제외 범위다. 작은 창 모드가 그 요구를 얼마나 대신할 수 있는지 확인이 필요하다.
