# F06 파티별 명령 표시

| 항목 | 내용 |
|---|---|
| 단계 | Phase 1 (MVP) |
| 우선순위 | Must |
| 관련 문서 | [F05 전술 HUD](F05-tactical-hud.md), [도메인·프로토콜](../02-domain-and-protocol.md) §3 슬롯 규칙 |

## 왜 필요한가

- 음성으로는 모든 파티의 명령을 다 들어야 내 몫을 골라낼 수 있다. 화면은 내 몫만 골라 보여 줄 수 있다.
- 다만 다른 파티의 상황도 알아야 할 때가 있다. 예를 들어 우리 파티를 지원하러 오는 파티가 있는지 알아야 한다.

## 아이디어

| 안 | 내용 | 판단 |
|---|---|---|
| 내 파티 우선 배치 | 내 파티 카드를 가장 크게, 다른 파티는 작게 | **채택** |
| 전체 명령 별도 줄 | 전체 대상 명령은 내 파티 카드 아래에 한 줄로 | **채택**. 내 파티 명령과 전체 명령이 다를 때 둘 다 보여야 한다 |
| 지원 관계 표시 | "2파티가 3파티를 지원" 명령이면 3파티 카드에 "2파티 지원 옴" | **채택**. 지원받는 쪽이 기다릴지 판단할 수 있다 |
| 함께 받은 파티 표시 | "1·2파티 함께" | **채택**. 누구와 같이 움직이는지 알 수 있다 |
| 파티별 확인 응답 | 파티원이 "확인" 버튼을 누름 | Phase 3. 전투 중 누르기 어렵고 MVP 범위를 넘는다 |

## 표시 규칙

| 내 파티의 상황 | 내 파티 카드 | 전체 명령 줄 |
|---|---|---|
| 내 파티 대상 명령이 가장 최근 | 그 명령 | 마지막 전체 명령이 있으면 작게 |
| 전체 명령이 가장 최근 | 전체 명령 ("전체" 배지) | 숨김 (중복) |
| 명령 없음 | "명령 없음" | 마지막 전체 명령이 있으면 작게 |
| 파티 미선택 | 카드 없음. 모든 파티를 같은 크기의 격자로 | 위쪽에 표시 |

내 파티 카드는 항상 슬롯 규칙(도메인 §3.1)의 "현재 명령"을 그대로 보여 준다. 화면이 따로 계산하지 않는다.

## 기능 요구사항

| ID | 요구사항 |
|---|---|
| FR-F06-1 | 내 파티의 현재 명령을 F05의 큰 카드로 보여 준다 |
| FR-F06-2 | 현재 명령이 전체 대상이면 "전체" 배지를 붙인다 |
| FR-F06-3 | 현재 명령의 대상이 여러 파티면 함께 받은 파티를 표시한다 |
| FR-F06-4 | 다른 파티가 내 파티를 지원하라는 명령을 받으면 내 카드에 "N파티 지원 옴"을 표시한다 |
| FR-F06-5 | 다른 모든 파티의 현재 명령을 작은 격자로 보여 준다. 파티 순서는 파티 번호 순이다 |
| FR-F06-6 | 파티를 선택하지 않은 사용자에게는 모든 파티를 같은 크기로 보여 준다 |
| FR-F06-7 | 최근 이력(최대 50건)을 시간 역순으로 보여 준다. "내 파티 관련만 / 전체" 필터가 있다 |
| FR-F06-8 | 이력 항목에는 시각, 대상, 행동, 위치, 상태(정정·취소)를 보여 준다 |
| FR-F06-9 | 파티 구성이 바뀌면 격자를 즉시 다시 그린다. 번호·이름만 바뀐 경우 내 카드 위치는 그대로다 |
| FR-F06-10 | 다른 파티 격자의 칸을 누르면 그 파티 명령을 크게 볼 수 있다. 내 파티 설정은 바뀌지 않는다 |

## 사용자 스토리

### US-F06-1 내 명령만 크게
동맹원으로서, 3파티를 골랐으면 3파티 명령을 가장 크게 보고 싶다.

1. "1파티 공격" 다음 "3파티 방어 우측"이 오면 내 카드는 "방어 우측"으로 바뀌고, 1파티 칸은 "공격"으로 남는다.
2. "전체 집결 중앙"이 오면 내 카드는 "집결 중앙"에 "전체" 배지가 붙는다.
3. 그 뒤 "1·2파티 공격"이 와도 내 카드는 "전체 집결 중앙"을 유지한다.

### US-F06-2 지원 관계
동맹원으로서, 우리 파티에 지원이 오는지 알고 싶다.

1. "2파티 3파티 지원"이 오면 3파티 카드에 "2파티 지원 옴"이 보인다.
2. 2파티 명령이 다른 명령으로 바뀌면 이 표시가 사라진다.

### US-F06-3 지난 명령 확인
동맹원으로서, 놓친 명령의 흐름을 다시 보고 싶다.

1. 이력을 열면 최근 명령이 시간 역순으로 보인다.
2. "내 파티 관련만" 필터는 내 파티 대상과 전체 대상만 보여 준다.
3. 취소된 명령은 줄이 그어져 보이고, 정정된 명령은 정정 후 내용과 함께 보인다.

### US-F06-4 파티 미선택
동맹원으로서, 아직 파티가 정해지지 않았어도 전체 상황을 보고 싶다.

1. 파티를 고르지 않으면 모든 파티가 같은 크기 격자로 보인다.
2. 화면 위에 "내 파티를 고르면 내 명령을 크게 볼 수 있습니다" 안내가 보인다.

## 열린 질문

- 파티가 8개 이상이면 휴대폰 격자가 좁아진다. 휴대폰에서는 다른 파티를 가로 스크롤로 보여 줄지 Phase 2에서 결정한다.
