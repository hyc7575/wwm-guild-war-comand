# 가정 목록과 검증 계획

작성일: 2026-11-26 · 방법: 8개 위험 범주 (Value, Usability, Viability, Feasibility, Ethics, Go-to-Market, Strategy, Team)

새 제품 아이디어의 상당수는 기대만큼 동작하지 않는다. 아래 가정은 모두 "아직 증명되지 않음"으로 본다.

- **확신도**: 높음 / 중간 / 낮음. 지금 가진 근거의 양이다.
- **영향**: 틀렸을 때 서비스가 받는 타격이다.
- **우선 검증**: 확신도가 낮고 영향이 큰 가정. Phase 0에서 먼저 확인한다.

## 검증 순서

1. **이번 주**: A-1 메인오더 인터뷰, A-2·A-3 동맹원 설문. 비용이 가장 적고 결과에 따라 방향이 바뀐다.
2. **Phase 0 1주차**: A-9, A-7, A-8 기술 확인. 하루 단위로 답이 나온다.
3. **Phase 0 2~3주차**: A-5, A-6, A-26 데이터셋 측정. Wizard of Oz 시범으로 A-12, A-4, A-21 관찰.
4. **Phase 1 시범 운영**: 나머지.

A-1이 "아니오"로 나오면 [프리모템](04-pre-mortem.md)의 대리 청취 모드나 운영자 수동 모드로 방향을 바꾼다.
